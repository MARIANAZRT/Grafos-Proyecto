# Grafos-Proyecto
construccion de un grafo con sus propiedades

## 🛠️ Requisitos e Instalación

Este proyecto está desarrollado en Python y utiliza librerías externas para la construcción matemática de grafos y su visualización interactiva en la web.

### Librerías Utilizadas

* **`networkx`**: Para la creación de la estructura del grafo $G = (V, A)$, consulta de propiedades (vértices y aristas) y el cálculo del emparejamiento óptimo.
* **`pyvis`**: Para generar la representación gráfica e interactiva del grafo en un archivo HTML navegable.
* **`matplotlib`**: Para renderizar y exportar imágenes estáticas del grafo.

---

### Comando de Instalación

Ejecuta el siguiente comando en tu terminal para instalar todas las dependencias necesarias de una sola vez:

```powershell
pip install networkx pyvis matplotlib
